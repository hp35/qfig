# Example MetaPost code for drawing simple beam splitters and interferometers

This repo contains illustrative examples of MetaPost source code for a couple
of figures on a couple of classic interferometer setups, created as a template
for diploma workers Edvin Lundberg and Joel Grenehed in their BSc Thesis
"Partial Coherence From Classical Optics to Quantum Optics in Optical
Microlithography" (Master’s Programme in Engineering Physics, Uppsala
University, 2026).

In order to regenerate the figures from the MetaPost sources, use the
enclosed Makefile and just run 'make' in the current directory.
